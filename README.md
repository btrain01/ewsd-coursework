🎓 eTutoring System

A web-based, role-based eTutoring platform developed as part of the Enterprise Web Software Development (COMP1640) coursework. The system is designed to facilitate structured communication and interaction between students and personal tutors within a university environment.

📌 Project Overview

The eTutoring system provides a centralised platform where students, tutors, and authorised staff can interact efficiently. It supports key academic activities such as messaging, meeting scheduling, tutor allocation, and monitoring of student engagement.

🚀 Key Features

🔐 Role-Based Access Control
- Different interfaces for Students, Tutors, and Staff
- Secure authentication system

📊 Personalised Dashboards
- Students: Overview of interactions and activities
- Tutors: List of assigned students
- Staff: Administrative monitoring tools

💬 Messaging System
- Internal communication between students and tutors
- Message tracking and history

📅 Meeting Management
- Schedule and manage tutor-student meetings
- Organised booking system

👥 Tutor Allocation
- Assign and reassign tutors to students
- Bulk allocation support

📁 Content Interaction
- Blog and document-related features
- Structured engagement between users

📱 Responsive Design
- Compatible with desktop, tablet, and mobile devices

🛠️ Technologies Used
- Frontend: HTML, CSS, JavaScript

- Backend: ASP.NET C#

- Database: PostgreSQL
